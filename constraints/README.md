# 📌 Constraints (XDC)

תיקייה זו מכילה את אילוצי החומרה הפיזיים עבור כרטיס ה-Artix-7.

## 🗺️ Pin Mapping Overview
*   **VGA Pins:** מנותבים לנגדים וליציאת ה-VGA על הכרטיס.
*   **Camera Pins (Pmod):** מנותבים לחיבורי ה-Pmod של הכרטיס (יש לוודא תאימות מתחים מול ה-OV7670).
*   **Clock & Reset:** הגדרות תדר שעון ראשי (100MHz) וכפתור איפוס פיזי.
