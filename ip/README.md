# 🧩 Intellectual Property (IP) Cores

תיקייה זו מכילה את רכיבי החומרה המוכנים (IP Blocks) שנוצרו על ידי Vivado (Xilinx) ומשולבים בפרויקט.

## 📦 Installed Modules

* **`clk_wiz_0` (Clock Wizard)** ⏱️
  רכיב האחראי על סינתזת תדרי שעון מדויקים. הוא לוקח את שעון הבסיס של הכרטיס (100MHz) ומייצר ממנו את התדרים הנדרשים עבור בקר המצלמה (OV7670) ובקר התצוגה (VGA).

* **`blk_mem_gen_0` (Block RAM Generator)** 💾
  משמש כזיכרון הפנימי של המערכת (Frame Buffer). רכיב זה אוגר את הפיקסלים שנקלטים מהמצלמה ומאפשר קריאה מהירה שלהם החוצה לטובת עיבוד התמונה (זיהוי הנפילות) והצגתם על המסך.
