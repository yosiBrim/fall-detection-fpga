# 🧪 סביבת בדיקות (POC) לפורמטים של מצגת הגמר

תיקייה זו מכילה בדיקת היתכנות (Proof of Concept) עבור 5 טכנולוגיות שונות להמרת קוד למצגת מקצועית. המטרה היא לבחון איזו סביבה מתמודדת בצורה הטובה ביותר עם:
1. יישור לימין (RTL) של השפה העברית.
2. שילוב מונחים באנגלית (`FPGA`, `VHDL`, `BRAM`) בלי לשבור את המשפטים.
3. שילוב תמונות וטבלאות בצורה חלקה.

---

## 🛠️ מדריך הרצה לכל פורמט

### 1. Marp (קובץ `1_marp_test.md`) - 🏆 ההמלצה המובילה
מנוע חזק שהופך Markdown למצגות שקופיות נקיות.
* **הכנה:** התקן את התוסף `Marp for VS Code` מתוך חנות התוספים של VS Code.
* **איך מריצים (Preview):** פתח את הקובץ. למעלה מימין יופיע סמל קטן של Marp (משולש/שקף). לחץ עליו כדי לפתוח תצוגה מקדימה שמתעדכנת בזמן אמת כשאתה מקליד.
* **איך מייצאים:** פתח את שורת הפקודות ב-VS Code (`Ctrl + Shift + P`), חפש את הפקודה `Marp: Export slide deck`, ובחר האם לייצא ל-PDF או ל-PowerPoint (.pptx).
* **טיפ לתוצאות יפות:** השתמש בבלוק ה-`style` בראש הקובץ כדי לשלוט בגדלי גופנים, צבעים ויישור בדיוק כמו ב-CSS.

### 2. Reveal.js HTML (קובץ `2_revealjs_test.html`)
מצגת מבוססת דפדפן, נותנת שליטה פיקסל-פר-פיקסל.
* **הכנה:** אין צורך בהתקנות מיוחדות (הקוד מושך את הספריות מהאינטרנט). מומלץ להתקין את התוסף `Live Server` ב-VS Code כדי שהדפדפן יתרענן אוטומטית בכל שמירה.
* **איך מריצים:** לחץ קליק ימני על הקובץ ב-VS Code ובחר `Open with Live Server`, או פשוט פתח את הקובץ ישירות בדפדפן כרום.
* **איך מייצאים:** בדפדפן, הוסף לשורת הכתובת `?print-pdf` (למשל `file.html?print-pdf`), לחץ `Ctrl + P` ושמור כ-PDF.
* **טיפ לתוצאות יפות:** עטוף מילים באנגלית בתגית `<span class="ltr-text">Word</span>` (כמו שעשיתי בקוד) כדי להבטיח שהן לא יהפכו את כיוון המשפט.

### 3. Typst (קובץ `3_typst_test.typ`)
הדור הבא של מסמכים אקדמיים (מהיר ונקי בהרבה מ-LaTeX).
* **הכנה:** הדרך הקלה ביותר היא לעבוד בענן. פתח משתמש חינמי ב- [Typst App](https://typst.app/). (לחלופין, התקן את התוסף `Typst Preview` ב-VS Code).
* **איך מריצים:** העתק את הקוד לפרויקט חדש ב-Typst App ותראה את הקימפול מתבצע מיידית בכל הקלדה.
* **איך מייצאים:** לחץ על כפתור ההורדה (Download PDF) בצד ימין למעלה באפליקציית הרשת.
* **טיפ לתוצאות יפות:** השתמש בפונקציית `#text(dir: ltr)[English Word]` סביב מילים באנגלית כדי לשמור על סדר הקריאה.

### 4. LaTeX + Beamer (קובץ `4_latex_test.tex`)
הסטנדרט האקדמי הישן והטוב.
* **הכנה:** אין צורך להתקין במחשב (זה כבד מאוד). פתח פרויקט ב-[Overleaf](https://www.overleaf.com/).
* **איך מריצים:** **קריטי:** לחץ על `Menu` (בצד שמאל למעלה ב-Overleaf) ושנה את ה-`Compiler` מ-pdfLaTeX ל-**XeLaTeX** (אחרת העברית לא תעבוד). הדבק את הקוד ולחץ `Recompile`.
* **איך מייצאים:** לחץ על כפתור הורדת ה-PDF בחלון התצוגה המקדימה.
* **טיפ לתוצאות יפות:** כל מילה או משפט באנגלית חייבים להיות עטופים ב-`\LRE{English}`.

### 5. Pandoc Markdown (קובץ `5_pandoc_test.md`)
כלי המרה ישיר משורת הפקודה.
* **הכנה:** עליך להתקין את תוכנת [Pandoc](https://pandoc.org/installing.html) על המחשב (בווינדוס אפשר דרך הטרמינל עם הפקודה `winget install pandoc`).
* **איך מריצים ומייצאים:** פתח טרמינל בתיקייה זו והרץ את הפקודה:
  `pandoc 5_pandoc_test.md -o output.pptx`
* **טיפ לתוצאות יפות:** התוצאה הבסיסית יכולה להיות קצת "אפורה". כדי לקבל עיצוב יפה באמת, אפשר לספק לפנדוק קובץ עיצוב של פאוורפוינט (Reference) דרך שורת הפקודה, אך זה דורש מעט התעסקות.
