פיתוח מערכת מבוססת FPGA להתראת נפילה

קליטת תמונה בזמן אמת ממצלמת OV7670 והצגתה דרך כרטיס Artix-7.
על מנת לאפשר עיבוד תמונה לזיהויי עמידה ממושכת לחולי דמנציה.
