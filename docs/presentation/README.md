# 🎓 פרויקט גמר - מצגת הגנה: בקר VGA ומימוש RTL

תיקייה זו משמשת לניהול, תכנון, עדכון ובנייה אוטומטית של מצגת ההגנה על בקר ה-VGA. הפרויקט מנוהל בשלבים (Roadmap) בהתאם לאישורים והערות המנחה (ערן), כדי להבטיח התקדמות מסודרת וגיבוי מלא של כל גרסה.

## 📁 מבנה התיקייה

* **`src/`:** קוד פייתון (`.py`) לייצור ושליטה במצגת.
* **`assets/`:** תמונות, תרשימים, דיאגרמות (RTL, ModelSim, ILA) וסרטונים המשולבים במצגת.
* **`output/`:** תוצרי הבנייה (קובצי `.pptx` סופיים). **מומלץ להוסיף ל-`.gitignore` כדי למנוע עומס על המאגר.**
* **`reference/`:** גיבוי של שקפי הבסיס (Base-line) שאושרו עד כה (PDF/תמונות).

## 🛠️ סביבת עבודה

**התקנת חבילות:**
```bash
pip install python-pptx
```

**בניית המצגת:**
```bash
python src/build_presentation.py
```

## 📝 תוכנית עבודה (Roadmap) ומעקב משימות

- [x] **אבן דרך:** אישור גרסת בסיס על ידי מנחה (ערן).
- [ ] תיקוני שגיאות כתיב וניסוח מילולי בשקפים המאושרים.
- [ ] דילול שקפים (1-2) עמוסים במלל ופיצולם למספר שקפים נקיים יותר.
- [ ] החלפת תמונות בשקפים ספציפיים לפי הצורך.
- [ ] כתיבה והוספה של תתי-הנושאים התיאורטיים החסרים שערן ביקש.

### חלק 2: סימולציות ModelSim (פרוטוקול VGA - ברמת Source)
- [ ] **הכנת השטח:** וידוא תיעוד הלוגיקה וה-Testbenches (מוכנים).
- [ ] **שקף 1:** מבוא לסימולציה והצגת הפרוטוקול - התמקדות בציר האופקי (Horizontal).
- [ ] **שקף 2:** תצוגת השעונים והמידע - איך המידע מתעדכן בהתאם לפרוטוקול.
- [ ] **שקף 3:** מדידת זמנים מדויקת בסימולציה (Pulse width, Front/Back porch, Display time, Sync pulse).
- [ ] **שקף 4:** השוואת מדידות הסימולציה מול הטבלה התיאורטית.

### חלק 3: המרה מדיגיטל לאנלוג (DAC) ורשת הנגדים
- [ ] הסבר על מתמטיקה ופיזיקה של המעגל: איך רשת הנגדים פועלת הלכה למעשה.
- [ ] פירוט תפקידי הביטים (MSB עד LSB) והשפעתם על חלוקת הזרם לכל צבע.
- [ ] חלוקת מתח: הסבר על הנגד הפנימי במסך שמייצג את העוצמה הנופלת של הערכים.
- [ ] הנגדים הטוריים: תפקיד שני נגדי ה-100 אוהם של הסנכרון (Horizontal & Vertical).

### חלק 4: אינטגרציית מערכת (BRAM ו-FPGA - מבנה פנימי)
- [ ] הוספת דיאגרמת RTL מ-Vivado (ממבט-על).
- [ ] תיחום ויזואלי: ריבוע **כחול** (ממשק בין זיכרון ל-VGA) וריבוע **אדום** (ממשק בין זיכרון למצלמה).
- [ ] הסבר על Dual Clock FIFO (מתוך הדוח): שוני בתדרים, א-סינכרוניות ועבודה נפרדת ללא תלות.

### חלק 5: סימולציית VGA Controller מול הזיכרון
- [ ] הצגת תהליך שליפת המידע ("מבחוץ" ל-VGA Controller).
- [ ] זרימת נתונים: ממחולל הכתובות (Address) אל הזיכרון, ההשלכה על `DOUTB`, והתרגום ליציאות ה-RGB.

### חלק 6: דיבוג בחומרה בזמן אמת (Vivado ILA)
- [x] **שקף 1 - רקע ILA:** למה צריך את זה (הדגמת שינויי RGB ביחס ל-DOUTB).
- [x] **שקף 2 - משאבי חומרה (Device View):** השוואת תמונות פיזיות של המערכת ב-FPGA עם ובלי ה-ILA (צריכת LUTs).
- [x] **שקף 4 - השוואת סימולציה למציאות:** ILA מול ModelSim, ניתוח הבדלים, עיכובים פיזיים (Delays).
- [ ] **שקף 3 - הדגמה חיה:** סרטון ריצת הסיגנלים בזמן אמת ב-ILA (*ממתין לגישה לבורד הפיזי*).
