# פרויקט גמר - מצגת הגנה: פרוטוקול VGA ומימוש RTL

תיקייה זו משמשת לניהול, עדכון ובנייה אוטומטית של מצגת ההגנה על בקר ה-VGA, בהתאם לדרישות ולשלבי ההתקדמות שאושרו.

## 📁 מבנה התיקייה

כדי לשמור על סדר לאורך שלבי הפיתוח של המצגת, התיקייה מחולקת בצורה הבאה:

* **`src/` (Source):** תיקייה זו מכילה את קוד הפייתון (`.py`) שאחראי על בניית המצגת. כל עדכון תוכן או עיצוב יתבצע כאן.
* **`assets/` (או `images/`):** תיקייה המכילה את כל משאבי המדיה (תמונות, דיאגרמות בלוקים, גרפים של תזמונים) המשולבים במצגת.
* **`output/`:** תיקייה זו תכיל את התוצר הסופי. לכאן יישמר קובץ ה-`.pptx` בכל פעם שנריץ את סקריפט הבנייה (מומלץ להוסיף את קבצי ה-pptx ל-`.gitignore` כדי למנוע עומס על הגיט, ולשמור רק את הקוד שמייצר אותם).
* **`reference/`:** תיקייה לגיבוי גרסאות שאושרו על ידי המנחה (PDF או תמונות של שקפים) כדי שתמיד נדע מהו קו הבסיס (Baseline) שלנו.
