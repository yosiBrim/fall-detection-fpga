# 🎓 פרויקט גמר - מצגת הגנה: בקר VGA ומימוש RTL

תיקייה זו משמשת לניהול, תכנון, עדכון ובנייה אוטומטית של מצגת ההגנה על בקר ה-VGA. הפרויקט מנוהל בשלבים (Roadmap) בהתאם לאישורים והערות המנחה (ערן), כדי להבטיח התקדמות מסודרת וגיבוי מלא של כל גרסה.

## 📁 מבנה התיקייה

* **`src/`:** קוד פייתון (`.py`) לייצור ושליטה במצגת.
* **`assets/`:** תמונות, תרשימים, דיאגרמות (RTL, ModelSim, ILA) וסרטונים המשולבים במצגת.
* **`output/`:** תוצרי הבנייה (קובצי `.pptx` סופיים). **מומלץ להוסיף ל-`.gitignore` כדי למנוע עומס על המאגר.**
* **`reference/`:** גיבוי של שקפי הבסיס (Base-line) שאושרו עד כה (PDF/תמונות).

## 🛠️ סביבת עבודה

**התקנת חבילות:**
```bash
pip install python-pptx
```

**בניית המצגת:**
```bash
python src/build_presentation.py
```

4. **הרצה:** ודא שהטרמינל מצביע לתיקייה שלנו, והרץ את פקודת הבנייה:

- [x] **שקף 2:** תצוגת השעונים והמידע - איך המידע מתעדכן בהתאם לפרוטוקול.
- [x] **שקף 3:** מדידת זמנים מדויקת בסימולציה (Pulse width, Front/Back porch, Display time, Sync pulse).

- [ ] 
### חלק 3: המרה מדיגיטל לאנלוג (DAC) ורשת הנגדים
-  [x]  הסבר על מתמטיקה ופיזיקה של המעגל: איך רשת הנגדים פועלת הלכה למעשה.
-   [x]  פירוט תפקידי הביטים (MSB עד LSB) והשפעתם על חלוקת הזרם לכל צבע.

-   [x]  הנגדים הטוריים: תפקיד שני נגדי ה-100 אוהם של הסנכרון (Horizontal & Vertical).

### חלק 4: אינטגרציית מערכת (BRAM ו-FPGA - מבנה פנימי)
- [x] הוספת דיאגרמת RTL מ-Vivado (ממבט-על).
- [x] תיחום ויזואלי: ריבוע **כחול** (ממשק בין זיכרון ל-VGA) וריבוע **אדום** (ממשק בין זיכרון למצלמה).
- [x] הסבר על Dual Clock FIFO (מתוך הדוח): שוני בתדרים, א-סינכרוניות ועבודה נפרדת ללא תלות.

### חלק 5: סימולציית VGA Controller מול הזיכרון
-  [x] הצגת תהליך שליפת המידע ("מבחוץ" ל-VGA Controller).
-  [x] זרימת נתונים: ממחולל הכתובות (Address) אל הזיכרון, ההשלכה על `DOUTB`, והתרגום ליציאות ה-RGB.
